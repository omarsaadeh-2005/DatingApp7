# DatingApp7 – Full-Stack Dating Application with AI Integration

A full-stack dating web application developed during a two-month Software Engineering Internship at Intalio.

The project was completed in two phases, progressing from guided full-stack development to implementing additional AI-powered features.

## Project Development

### Phase 1 – Full-Stack Application Development

During the first month of the internship, I followed structured video tutorials to develop a full-stack dating application and gain practical experience with frontend and backend technologies.

The application was built using Angular, ASP.NET Core, Entity Framework Core, and SQLite.

Core functionality included:
- User registration and JWT authentication
- User profile management
- Real-time messaging using SignalR
- Database management using Entity Framework Core
- Application deployment using Docker, GitHub Actions, and Fly.io

This version was successfully deployed and is accessible through the live demo below.

### Phase 2 – AI Integration and Enhancement

During the second month, I focused on extending the application by integrating AI-powered functionality using Google Gemini and Ollama.

The additional features included:
- **AI-Assisted Identity Verification:** Incorporating AI into the user identity verification process.
- **Photo Moderation:** Using AI to assist with reviewing user-uploaded images.
- **Smart Matching:** Integrating AI-powered functionality to improve user matching.

This phase provided hands-on experience working with AI models, integrating external services, and extending an existing full-stack application.
